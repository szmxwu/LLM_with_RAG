# 放射医疗场景多智能体系统

## 系统概述

这是一个专为放射医疗场景设计的多智能体系统，结合大语言模型（LLM）与检索增强生成（RAG）技术，提供智能问答、文本处理、知识检索和决策辅助等功能。系统旨在辅助放射科医生进行专业诊断决策，提高医疗质量和效率。

## 核心功能

### 1. 智能问答与决策辅助
- 基于放射专业知识库的智能问答
- 放射诊断与病理诊断符合率判断
- 患者病史总结与检查要点提醒

### 2. 知识管理
- 支持多种格式文档上传（PDF、DOCX、PPTX、XLSX等）
- 文档自动解析与索引
- 知识库文档管理（查看、删除）

### 3. 病例检索
- 基于关键词的病例图片检索
- 相关病例推荐

### 4. 多智能体架构
系统采用双智能体架构，根据问题复杂度自动选择合适的处理方式：
- **Simple Agent（简单对话智能体）**：处理日常简单问答，具有短期记忆和自我认知能力
- **Knowledge Agent（知识智能体）**：处理复杂问题，能够拆解问题、查询知识库并汇总回答

### 主要组件说明

#### agent_server.py - 主服务文件
系统核心服务，基于FastAPI构建，提供RESTful API接口：
- WebSocket连接管理
- 智能体调度与路由
- API接口实现
- 文件上传与处理
- 日志管理

#### llm_func.py - 大模型功能集
封装了与大语言模型交互的各种功能：
- Text2SQL转换
- 符合率匹配
- RAG查询
- 文件处理

#### RAGFLOW_SDK.py - RAG交互SDK
与RAGFLOW 0.15交互的SDK，已修复官方bug：
- 文件上传、下载、检索
- 知识库管理
- 文档解析与处理

#### process_docs.py - 文档处理模块
执行文件格式转换和分割功能：
- PDF页转换为图像
- PPTX解析
- 文档分割处理

#### simple_agent.py - 简单对话智能体
处理简单对话的智能体：
- 短期记忆管理（最近10轮对话）
- 流式响应输出
- 自我认知能力

#### knownlege_agent.py - 知识智能体
处理复杂问题的智能体：
- 问题拆解与分析
- RAG知识库查询
- 多源信息整合
- 长思考模式

## API接口说明

### 核心接口

#### GET /get_uuid
获取一个新的UUID，用于区分不同的对话会话
- 返回：16位随机UUID

#### POST /login
医院登录接口
- 参数：
  - hospitalID: 医院组织机构代码
  - hospitalName: 医院名称

#### POST /Coincidence
判断放射诊断和病理诊断是否相符
- 参数：
  - radology_result: 放射报告的诊断结论
  - pathlogy_result: 病理报告的诊断结论
- 返回：判断理由和结果（符合/基本符合/不符合）

#### POST /rag_ask
流式返回放射决策大模型的回答
- 参数：
  - question: 用户提出的问题
  - user_id: 对话ID（通过get_uuid获得）
  - chat_name: 聊天助手的名字
- 返回：流式文本响应

#### POST /patient_summury
总结患者的病史信息
- 参数：
  - history: 患者历史检查结果
  - modality: 准备进行的检查类型
  - studypart: 准备进行的检查部位
  - report: 近期相同部位检查结果
  - user_id: 对话ID
  - chat_name: 聊天助手的名字
  - html: 是否输出HTML格式
- 返回：患者病史总结和检查要点

#### POST /long_think
长思考模式，返回更详细的信息
- 参数：
  - question: 用户提出的问题
  - user_id: 对话ID
  - chat_name: 聊天助手的名字
- 返回：流式详细分析结果

#### GET /list_case
列出病例库中的相关病例图片
- 参数：
  - keywords: 病例关键词
- 返回：相关病例图片列表

#### GET /list_docs
列出指定知识库的所有文档
- 参数：
  - keyword: 查询关键词（可选）
- 返回：文档列表

#### DELETE /del_docs
删除指定文档
- 参数：
  - doc_id: 文档ID列表
- 返回：操作结果

#### POST /uploadfiles
上传知识库文档并解析（文档大小不得超过2G）
- 参数：
  - files: 文件列表
- 返回：上传结果

#### POST /uploadCaseFiles
上传病例文件
- 参数：
  - files: 文件列表
- 返回：上传结果

## 部署与配置

### 环境要求
- Python 3.8+
- FastAPI
- Uvicorn
- 相关Python依赖包（见requirements.txt）

### 环境变量配置
在.env文件中配置以下参数：
- API_KEY: RAGFLOW API密钥
- BASE_URL: RAGFLOW服务地址
- XINFERENCE: 本地模型API地址
- LLM_NAME: 模型名称
- DEFAUT_DATA: 默认知识库名称
- DEFAUT_CASE: 默认病例库名称
- ENDPOINT_IP: 前端Web服务地址和端口
- MAX_FILE_UPLOAD: 最大文件上传大小（MB）

### 启动服务
```bash
uvicorn agent_server:app --reload
```

## 使用场景

1. **日常诊断辅助**：医生可通过自然语言询问疾病相关信息，系统提供基于知识库的专业回答
2. **诊断符合率判断**：自动比放射诊断和病理诊断结果，判断其符合程度
3. **患者病史分析**：自动整理患者历史检查记录，为医生提供结构化病史总结
4. **检查要点提醒**：根据患者病史和即将进行的检查，提醒医生阅片时需要注意的要点
5. **知识库维护**：医院可上传和管理专业知识文档，构建专属知识库
6. **病例学习**：通过关键词检索相关病例图片，辅助医生学习和诊断

## 技术特点

1. **多智能体架构**：根据问题复杂度自动选择合适的处理方式，提高效率
2. **流式响应**：提供类似真人对话的流式输出体验
3. **记忆机制**：Simple Agent具备短期记忆能力，可记住对话历史
4. **知识检索**：基于RAG技术，确保回答的专业性和准确性
5. **多模态支持**：支持文本、图像等多种信息形式
6. **WebSocket实时通信**：支持实时文献内容推送
7. **文档处理能力**：支持多种格式文档的上传、解析和检索
